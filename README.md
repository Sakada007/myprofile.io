# Soeung Sakada — Portfolio Website

A responsive, dark-tech personal portfolio built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — page content and sections
- `styles.css` — complete responsive styling
- `script.js` — mobile menu, reveal animation, and footer year
- `assets/` — place your profile photo and future project images here

## Deploy

### GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `assets/`.
3. Go to **Settings → Pages**.
4. Choose the `main` branch and `/ (root)`.
5. Save. GitHub will publish the site.

### Netlify
Drag the whole project folder into Netlify's deploy area.

### Vercel
Import the repository into Vercel. No build command is required because this is a static site.

## Included profile content

The profile includes your education history, previous chef work experience, software-development direction, technology skills, projects, learning journey, creative projects, and contact links.

## Personalize before publishing

Open `index.html` and update:
- Telegram URL
- YouTube URL
- TikTok URL
- Add your GitHub and LinkedIn links
- Add your professional email
- Add a real profile photo if you want one
- Add live project URLs as you publish projects
